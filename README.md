# chess-maine-event-scraper-haskell

Recently was reading "Get Programming in Haskell" by Will Kurt and was wanting to try applying what I was learning. My chess-maine-event-scraper hasn't been working for quite some time now (think they made changes to their website), so this seemed like a good enough project to play with.

## uses Stack

Assuming you have Stack installed, the typical commands:

- `$ stack build` to compile;
- `$ stack run` to compile (if needed) and run the executable;
